rclone-backup

A personal backup utility.

rclone-backup is a private, single-user application. It uses rclone to copy the owner's own backup files from a home server to the owner's own Google Drive account. It is not a product, not distributed, and has no users other than its owner.

All data is encrypted on the owner's own machine before upload, so the contents and filenames stored in Google Drive are unreadable without a key held only by the owner.

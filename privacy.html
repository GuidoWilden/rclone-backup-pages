Privacy policy

Last updated: 29 August 2026

rclone-backup is a personal, single-user backup application. Its only user is its owner. It is not offered to, distributed to, or usable by anyone else.

What it does

The application uploads the owner's own backup archives from the owner's own server to the owner's own Google Drive account, and downloads them again when restoring. That is its entire function.

What data is accessed

The application requests access to Google Drive solely in order to read and write the backup files it creates in the owner's own Drive. It does not read, index, analyse, or transmit any other files in the owner's Drive.

What data is collected

None. The application has no server, no analytics, no telemetry, and no database. Nothing is collected about the user, because the user is the owner and the software runs entirely on the owner's own hardware.

What data is shared

None. No data is sold, shared, transferred, or disclosed to any third party. The only party that receives data is Google Drive, acting as the owner's chosen storage provider, at the owner's own direction.

Encryption

All files are encrypted on the owner's own machine before being uploaded, using rclone's crypt backend. Both file contents and filenames are encrypted. The encryption key is held only by the owner and is never transmitted.

Retention and deletion

Backups are retained according to a rotation policy set by the owner, and older backups are deleted automatically. The owner may delete all stored data at any time by removing the files from Google Drive and revoking the application's access at myaccount.google.com/permissions.

Contact

This application has no users other than its owner. There is no support address; enquiries about this page are not monitored.
